# Prompts

La política de IA exige guardar aquí el texto **real** de los prompts enviados a la IA para programar, no un resumen.

- Un archivo por tema, por ejemplo `backend-pagos.md`, `bot-telegram.md`, `liquidacion.md`.
- Cada entrada lleva la fecha y hora, la herramienta y el prompt copiado tal cual.
- Guárdenlos a medida que trabajan; reconstruirlos al final no cumple.

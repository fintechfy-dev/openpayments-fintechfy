# Aviso

Mensaje en línea con ícono, título corto y una frase. Ancho completo del contenedor.

- `nt-aviso--exito`: algo salió bien. `--alerta`: hay que hacer algo pronto (mora, saldo). `--error`: algo falló en el sistema. `--info`: explicación tranquila (custodia, reglas).
- Usa `role="alert"` solo en errores; el resto `role="status"`.
- El título dice qué pasó; el texto dice qué sigue. Nunca culpar: "Tu cuota quedó pendiente", no "No pagaste".

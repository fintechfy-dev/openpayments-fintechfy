# AutorizacionCompleta

Página web móvil a la que vuelve la persona después de autorizar en su billetera (redirect del grant de Open Payments).

- Una sola idea: ya quedó. Ícono de éxito grande, `titulo-1` con el nombre, resumen en tarjeta y botón **Volver a Telegram** (`tg://resolve?domain=<bot>` con respaldo `https://t.me/<bot>`).
- Si la autorización falló, la misma página con aviso `--error` y botón "Intentar otra vez".
- Ancho de diseño 360px, todo dentro de la pantalla sin hacer scroll.

# Tabla

Lista de registros comparables: participantes, pagos, cuotas. Dentro de `nt-tabla-marco` (que hace scroll horizontal en móvil).

- `nt-tabla__num` para montos y números: alineados a la derecha, cifras tabulares.
- `nt-tabla__principal` para la columna que identifica la fila (nombre).
- Encabezados en mayúscula inicial, nunca en MAYÚSCULAS.
- En móvil con más de 4 columnas, prefiere tarjetas apiladas.

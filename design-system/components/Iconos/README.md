# Iconos

Íconos de línea, trazo 2px con puntas y uniones redondeadas, en una cuadrícula de 24×24, sin relleno: amables y legibles, nunca técnicos.

- En HTML usa `Natillera.icono("cuota")` (bundle.js) o pega el SVG con `class="nt-ico"`: hereda `currentColor`.
- Tamaños: `nt-ico--sm` 16px (badges, tablas), 24px por defecto, `nt-ico--lg` 32px (tarjetas, pantallas de éxito).
- Los SVG del grupo **Icons** están en tinta `#2C342F`; para otro color usa la versión inline.
- `reloj` y `punto` solo existen inline: se usan en badges de estado (pendiente, en mora, creada).
- Un ícono nunca va solo para comunicar un estado: siempre con su palabra.
- Para íconos que falten, usa Lucide (mismo trazo y lógica) y ajústalos a 2px.

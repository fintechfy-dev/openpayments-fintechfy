# TarjetaBienvenida

Invitación a una natillera: quién invita, las reglas en tres líneas y quién custodia el dinero, con una sola acción.

- Reglas siempre en este orden: cuánto y cada cuánto, desde/hasta (y fecha de liquidación), cuántas personas.
- El bloque de custodia es obligatorio y nombra al custodio y que nadie del grupo, ni el administrador, puede sacar la plata.
- Úsala como imagen del bot o como página web (enlace de invitación).

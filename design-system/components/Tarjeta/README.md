# Tarjeta

Contenedor de una idea: un dato, un estado o una regla. Radio `radio-lg`, padding `espacio-5`.

- `nt-card`: `superficie-elevada` + `borde` + `sombra-1`. Por defecto.
- `nt-card--destacada`: `primario-suave`, para el total del grupo o el dato más importante de la pantalla (una por pantalla).
- `nt-card--calida`: `secundario-suave`, para explicar la custodia del dinero y la bienvenida.
- Partes: `nt-card__cabeza` (título + badge o ícono), `nt-dato` con `nt-dato__etiqueta` y `nt-dato__valor` (`--md`, `--verde`).
- Los montos siempre con `formatoCOP` y cifras tabulares.

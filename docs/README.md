# Documentación del proyecto

| Documento | Qué es | Se actualiza |
|---|---|---|
| [`arquitectura.md`](arquitectura.md) | **Empieza aquí.** Las piezas del sistema, cómo se hablan, qué está construido y las decisiones tomadas | En el mismo PR que cambie una pieza, un flujo o una decisión (`.claude/rules/documentacion.md`) |
| [`plan-de-trabajo.md`](plan-de-trabajo.md) | El plan vigente de la hackathon: meta, frentes, contratos y orden de trabajo. Manda sobre el discovery | Cuando el equipo cambia el plan |
| [`checklist-entrega.md`](checklist-entrega.md) | La checklist de entrega contrastada con el repo | En cada commit o PR que cumpla o avance un punto (`.claude/rules/checklist-entrega.md`) |
| [`discovery/`](discovery/) | Diseño previo al evento: impactos, historias, criterios BDD y la especificación de la lógica financiera | No se actualiza: es registro congelado. Si el código se aparta, se anota en `arquitectura.md` |
| [`fuente/`](fuente/) | El documento original de la idea (PDF) | No se actualiza |

Cada carpeta de código tiene además su propio `README.md` (qué es, estructura, cómo correrla) y su `CLAUDE.md` (lo que Claude tiene presente al trabajar ahí).

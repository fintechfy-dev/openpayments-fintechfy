# EPIC-005 — Crédito desde el ahorro

> Sesión `natillera-2` · Fase 1 · Recorrido USMD: ACT-005 · Rebanada: REB-002

## Description

Tras cumplir un número de pagos, el participante pide un préstamo a la financiera; si no lo paga, el saldo se le descuenta en la liquidación.

## Business Value

Muestra el camino del ahorro al crédito formal (meta de negocio de Impact Mapping), pero depende de una financiera que aún no existe.

# EPIC-002 — Unirse a la natillera

> Sesión `natillera-2` · Fase 1 · Recorrido USMD: ACT-002 · Rebanada: REB-001

## Description

El participante llega por el enlace de invitación que comparte el administrador, acepta el monto y la periodicidad y autoriza una sola vez el cobro automático de su cuota con Open Payments.

## Business Value

Es el permiso de pago recurrente: el corazón del uso de Open Payments que mira el jurado y la condición para que el ahorro sea automático (PA1 en Impact Mapping).
